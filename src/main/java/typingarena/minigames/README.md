# src/main/java/typingarena/minigames 디렉터리

- 타자 미니게임 구현을 모아두는 패키지입니다.
- 현재는 `tugofwar` 서브패키지만 존재하며, JavaFX 기반 60초 줄다리기 타이핑 게임을 제공합니다.
- `GameLogic`은 단어 풀 로딩, 버프/트랩 비율(일반:아이템=7:3), 점수·콤보·아이템 처리까지 담당합니다.
- `RopePanel`은 로프 애니메이션과 단어 색상(일반/버프/트랩), 먹물 효과 등을 그립니다.
- 추가 미니게임을 만들 때는 새 패키지를 생성하고, README에 게임명·규칙·의존 리소스를 간략히 정리해 주세요.
