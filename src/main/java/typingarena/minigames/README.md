# src/main/java/typingarena/minigames 디렉터리

- 타자 미니게임 구현을 모아두는 패키지입니다. 현재 구성:
  1. `tugofwar` – 버프/트랩 단어로 로프를 당기는 줄다리기. `GameLogic`과 `TugOfWarWordGenerator`가 모디파이어 비율(일반 50%, 버프 25%, 트랩 25%), HUD, 로프 상태를 관리합니다. 트랩 효과: 먹물(3초) 또는 자소 분리(4초, 단어를 자모로 분리 표시). 싱글 모드에는 효과음/BGM(`TugOfWarSoundManager`)이 추가되었습니다.
  2. `castledefense` – 타이핑으로 적 웨이브를 막는 성 지키기 모드. 난이도/스테이지 관리 로직이 포함됩니다.
  3. `landgrab` – 10x10 보드를 차지하는 땅따먹기. `LandGrabLogic`과 `LandGrabPanel`이 타일 상태, 스플래시/먹물 애니메이션, 아이템을 담당합니다. 단어 비율은 일반 60% / 버프 20% / 트랩 20%이며, 버프(스플래시/보호막/콤보가드)와 트랩(먹물/EMP/혼란)이 포함됩니다. 콤보 10 이상이면 상대 타일을 즉시 빼앗으며, 보드는 플레이어 시점 기준(내 땅=파랑)으로 렌더링됩니다.
- 공통 리소스(`words/ko.json`)를 사용하므로 단어 규칙을 바꿀 때는 두 게임 모두 영향받을 수 있습니다.
