# 🕹️ 미니게임: 땅따먹기 (Land Grab)
Typing Arena의 실시간 1:1 타자 대결 미니게임입니다. 제한 시간 내에 AI보다 더 많은 타일을 점령하세요! 온라인 매칭에서는 현재 서버 AI가 상대 역할을 합니다(PvP 입력 로직 준비 중).

## 🏁 게임 목표
제한 시간: 60초

승리 조건: 60초가 지났을 때, AI보다 더 많은 타일(칸)을 차지하고 있으면 승리합니다.

게임 보드: 10x10 (총 100칸)의 그리드에서 AI와 실시간으로 땅을 뺏고 뺏깁니다.

## ⌨️ 기본 규칙: 땅 뺏기 메커니즘
타일은 총 3가지 상태로 존재하며, 어떤 상태의 타일을 입력하느냐에 따라 결과가 다릅니다.

**⬜ 빈 땅 (흰색 타일)**

단어를 정확히 입력하면 내 땅 (파란색)이 됩니다.

(결과: 내 점수 +1)

**🟥 AI 땅 (빨간색 타일)**

단어를 정확히 입력하면 빈 땅 (흰색)으로 되돌아갑니다. (땅을 빼앗아 중립화시킵니다.)

(결과: AI 점수 -1)

**🟦 내 땅 (파란색 타일)**

이미 점령한 땅입니다.

(결과: 단어를 입력해도 아무 효과가 없습니다.)

**🤖 AI의 움직임**

AI는 약 2초마다 한 번씩 타일을 점령합니다.

AI는 빈 땅을 우선적으로 점령하며, 빈 땅이 없다면 플레이어의 땅을 공격하여 빈 땅으로 되돌립니다.

## ⚡️ 특수 단어 (아이템)
타일 위의 단어는 일정 확률로 '버프' 또는 '트랩' 효과를 가집니다. 현재 확률은 버프 15% / 트랩 15% / 일반 70%입니다.

**<font color="#0064C8">💎 버프 (파란색 단어): 스플래시!</font>**

효과: 단어 입력 성공 시, 해당 타일을 점령함과 동시에 상하좌우 인접한 타일 중 하나를 무작위로 추가 공격/점령합니다.

시각 효과: 단어를 맞춘 위치에서 "스플래시!" 텍스트가 떠오르는 애니메이션이 재생됩니다.

**<font color="#D04444">🐙 트랩 (빨간색 단어): 먹물!</font>**

효과: 단어 입력 성공 시, 해당 타일을 점령하지만 3초간 화면이 어두워지는 '먹물' 효과가 발동됩니다.

시각 효과: "먹물!" 텍스트와 함께 3초간 게임 화면이 어두워져 단어 식별이 어려워집니다.

## 🏆 게임 종료 및 승패 판정
다음 두 가지 조건 중 하나가 만족되면 게임이 즉시 종료됩니다.

시간 초과: 60초의 제한 시간이 모두 지났을 때

전장 점령: 100칸의 모든 타일이 '내 땅' 또는 'AI 땅'으로 채워졌을 때

게임 종료 시점의 **'내 점수(파란색 칸 수)'**와 **'AI 점수(빨간색 칸 수)'**를 비교하여 승패가 결정됩니다.
