# 🕹️ 미니게임: 땅따먹기 (Land Grab)
Typing Arena의 1:1 타자 대결 모드. 60초 동안 10x10 보드를 두고 상대보다 많은 타일을 점령하면 승리합니다.

## 기본 규칙
- 제한 시간: 60초. 전장(100칸)이 모두 채워지면 조기 종료.
- 입력: 보드에 보이는 단어를 정확히 타이핑 후 Enter.
- 점수/콤보: 내 땅(파랑)/상대 땅(빨강)을 점령하면 점수 +1, 빈칸(흰색)을 빼앗으면 점수 -1. 콤보는 연속 성공 시 증가하며, `콤보 10+`이면 상대 땅을 바로 내 땅으로 전환합니다.
- 시점 정렬: 내 타일은 항상 파랑, 상대 타일은 빨강으로 렌더링됩니다(온라인/싱글 모두 적용).

## 단어·아이템
- 단어 소스: `src/main/resources/words/ko.json` (싱글·멀티 공용).
- 모디파이어 비율: 일반 60% / 버프 20% / 트랩 20%.
- 버프: 스플래시(인접 1칸 추가 점령), 보호막 5초(상대 공격 무효), 콤보가드 5초(콤보 유지).
- 트랩: 먹물(타일 블라인드), EMP(상대 타일 최대 3개 중립화), 혼란(상대 단어 좌우 반전).
- HUD에는 보호막/혼란/잉크 등 효과가 표시되며, 아이템 발동 시 애니메이션과 사운드가 재생됩니다.

## 모드별 특징
- 싱글: `LandGrabGame`이 AI와 연습 모드처럼 동작(보드는 동일).
- 멀티: `LandGrabOnlineStage`가 서버 세션과 동기화하며, 종료 후 `GAME_REMATCH_REQUEST`로 동일 sessionId에서 재시작할 수 있습니다.
- 뷰: `LandGrabMatchView`와 `LandGrabPanel`이 보드, 아이템 연출, 자동 닫힘 오버레이(30초)를 담당합니다.

## 밸런스/소스 참고
- 핵심 로직: `core/landgrab/LandGrabLogic.java` (모디파이어 확률, 아이템 효과, 콤보 10+ 규칙).
- 이펙트/사운드: `LandGrabEffects`, 리소스 `src/main/resources/sounds/landgrab/*`.
- 서버 동기화: `server/session/LandGrabSession.java`에서 상태 브로드캐스트, 재경기 처리.
