# src/main/resources 디렉터리

- 실행 시 클래스패스에 포함되는 설정 파일, 이미지, 언어 리소스 등을 저장하는 경로입니다.
- `words/ko.json`은 줄다리기/땅따먹기(싱글·멀티 모두)에서 사용하는 기본 한글 단어 목록을 JSON 배열 형태로 보관합니다.
- `words/ko_easy.txt`, `ko_medium.txt`, `ko_hard.txt`는 참고용 샘플이며 필요 시 JSON 형식으로 변환해 사용할 수 있습니다.
- 차후 사운드, 이미지, 추가 설정 JSON 등을 추가할 때도 이 위치를 활용해 주세요.
